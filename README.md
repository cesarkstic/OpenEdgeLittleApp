# OpenEdgeLittleApp
Small App using Sports 2020 DB

Dir Structure

OpenEdgeLittleApp/
├── src/              # Standalone test programs for Customer, Order and OrderLine tables
│   ├── exceptions/   # User defined exeptions
│   ├── business/     # Business Objects layer
│   ├── data/         # Data Access layer
│   ├── dataset/      # Datasets .i include files
│   ├── db/           # A copy of Sports2020 test db
│   ├── entities/     # Business Logic layer
└── .gitignore        # Excludes .r files, logs, temp files
└── CustomerTest.p    # Customer test program 
└── OderTest.p        # Order test program 
└── OderListTest.p    # Order Line test program 
└── TotalByOrderTest.p  # Business entities test program
