# OpenEdgeLittleApp

**Small App using Sports 2020 DB**

---

## About

OpenEdgeLittleApp is a sample **Progress OpenEdge ABL** application that demonstrates business logic and data interactions using the **Sports 2020** sample database.  
It follows a structured approach, with layers for business logic, data access, and testing.

---

## Project Structure

```
├── business/        Layer hosting business logic and validation
├── data/            Data access and queries
├── datasets/        Schema or temp-table definitions
├── db/              Database connection utilities
├── entities/        Business entity definitions
├── exceptions/      Custom exception handlers
├── test/unit        Unit Tests
├── .dbconnection    Configuration for DB connectivity
├── build.config     Build instructions
├── *.p Test Files   CustomerTest.p, OrderTest.p, OrderLineTest.p, TotalByOrderTest.p
├── .gitignore       Files excluded from version control
└── README.md        Project documentation
```
