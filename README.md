# OpenEdgeLittleApp
Small App using Sports 2020 DB

Dir Structure

OpenEdgeLittleApp/<br>
├── src/<br>
│   ├── bo/           # Business Objects layer<br>
│   ├── bl/           # Business Logic layer
│   ├── dl/           # Data Access layer
│   ├── services/     # REST service entry points
│   ├── common/       # Shared utilities and constants
│   ├── include/      # .i include files
│   ├── ui/           # Optional UI programs (.p)
├── test/
│   ├── unit/         # ABLUnit tests for classes
│   ├── integration/  # PASOE integration tests
├── docs/             # Diagrams, documentation, notes
└── .gitignore        # Excludes .r files, logs, temp files
